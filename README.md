# Лабораторная работа №6: Функции

## Автор
Тенц Ангелина (Вариант 27) 

## Цель
Научиться выделять повторяющиеся вычисления в функции с понятными параметрами и результатом, передавать массив вместе с его размером. Отделять ввод и вывод от вычислений, повторно использовать функцию для разных данных.

## Описание
Программа запрашивает границы интервала (a, b) и три массива X, Y, Z размерами n, m, k  соответственно. С помощью функции counter определяется количество элементов каждого массива, не попадающих в интервал (a, b).

## Исходные данные
- Левая и правая границы интервала a, b.
- Размеры массивов X, Y, Z.
- Элементы массивов X, Y, Z

## Ожидаемый результат
- Количество элементов массива X, не попадающих в интервал (a, b).
- Количество элементов массива Y, не попадающих в интервал (a, b).
- Количество элементов массива Z, не попадающих в интервал (a, b).
